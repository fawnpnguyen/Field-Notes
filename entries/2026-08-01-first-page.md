Started the list today. Not the packing list — the *other* list. The one where I write down why I'm actually doing this before I forget and just let it become a vacation.

Reasons so far:

1. I have never once, in twenty-some years of writing slides for other people's attention spans, finished a page that was only for me.
2. Vietnam has been "someday" for a decade. Someday is a date that doesn't exist on a calendar, which is a very convenient way to never book the flight.
3. If I don't write it down now, I'll edit the memory into something cleaner than it was. I'd rather keep the messy version.

More soon. Probably with a photo of something I've already lost.
