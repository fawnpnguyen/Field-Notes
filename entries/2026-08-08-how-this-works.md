This is a journal entry. Every entry is just a markdown file in the `entries/` folder, named `YYYY-MM-DD-a-short-slug.md`.

Drop a photo in and reference it like this:

```
![A caption for the photo](images/2026-08-08/beach.jpg)
```

Run the build script, and it turns every file in `entries/` into a page in `site/`, newest first, with a spine of dates down the side so you can page back through the year — like flipping through a real notebook.

Nothing here ever leaves your machine unless you push it to your own private GitHub repo. No public hosting, no tracking, no account required to read it back — just you, later, with a cup of coffee, deciding which pages are good enough for the book.
